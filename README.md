## 🎯 Tujuan Project

Project ini dibuat murni untuk **belajar web development** dari dasar.  
Tidak ada framework, tidak ada shortcut — hanya HTML, CSS, dan JavaScript vanilla.

Fokus utamanya:
- Memahami struktur HTML yang semantik
- Styling layout dengan CSS murni
- Interaktivitas dasar dengan JavaScript
